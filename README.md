Rheumatology Disease Prediction System

Overview

The Rheumatology Disease Prediction System is a machine learning-based project developed using Python to predict rheumatological disease categories based on symptom-related data.

The project uses a symptom dataset and machine learning classification algorithms to explore how machine learning can be applied to healthcare data.

Objectives

* Analyze rheumatological symptom data.
* Implement machine learning classification algorithms.
* Predict disease categories using symptom-related features.
* Explore the application of supervised learning in healthcare.
* Demonstrate data processing and predictive modeling.

Technologies Used

* Programming Language: Python
* Data Processing: Pandas, NumPy
* Machine Learning: Scikit-learn
* Dataset Format: CSV

Machine Learning Algorithms

1. Decision Tree Classifier

The Decision Tree Classifier is a supervised machine learning algorithm that uses decision rules to classify data based on input features.

In this project, it is used to classify rheumatological disease categories using symptom-related data.

2. Gaussian Naive Bayes

Gaussian Naive Bayes is a probabilistic classification algorithm based on Bayes’ theorem. It assumes that numerical features follow a Gaussian distribution within each class.

In this project, it is used to estimate the probability of different disease categories based on the available symptom features.

Dataset

The project uses the following dataset:

data/dataset_rheumatology_symptoms.csv

The dataset contains symptom-related features used for machine learning-based disease classification.

Installation and Setup

Prerequisites

* Python 3.9 or later
* pip package manager

Install Dependencies

Run the following command from the root directory:

pip install -r requirements.txt

Run the Project

Run the following command from the root directory:

python src/main.py

Ensure that the dataset path specified in the Python code matches the actual location of the CSV file inside the data directory.

Methodology

1. Data Loading: Load the rheumatology symptom dataset from the CSV file.
2. Data Preprocessing: Prepare the data for machine learning.
3. Model Training: Train the Decision Tree and Gaussian Naive Bayes classifiers.
4. Disease Prediction: Generate predictions using the trained models.
5. Model Evaluation: Evaluate model performance using appropriate metrics, where implemented.
